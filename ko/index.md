# CarryOver - iPhone에서 저장, Mac에서 이어서

iPhone 공유 메뉴에서 게시물, 링크, 이미지와 아이디어를 저장하고 Mac에서 이어서 처리하세요. 미완료 항목 보관, iPhone·iPad·Mac 검색, 알림과 완료 항목 복원을 지원합니다.

휴대폰 공유 메뉴에서 저장하고, Mac에서 원문을 열어 이어서 처리하세요.

## 지금 저장하고 나중에 실행

### 공유 메뉴에서 저장

링크, 게시물, 아이디어를 CarryOver로

### 저장하고 나중에 처리

미완료 항목은 계속 목록에 남아요

### Mac에서 이어서 처리

출처를 열고 확인한 뒤 완료하세요

### 완료해도 다시 확인

완료한 항목은 기록에 남아요

## 빠르게 저장하고, 다음 행동으로 이어가세요

### 공유하거나 직접 기록

지원하는 앱의 시스템 공유 메뉴에서 텍스트, 링크 또는 이미지를 저장하세요. CarryOver에서 아이디어를 직접 기록할 수도 있습니다.

### 미완료 항목을 계속 보관

미완료 항목은 저장한 지 오래되어도 목록에 남습니다. 실제로 처리한 뒤 완료로 표시하세요.

### 저장한 내용은 어디서나 검색

iPhone, iPad와 Mac에서 제목, 본문과 출처 URL을 검색하세요. 미완료 목록과 기록 모두 검색할 수 있습니다.

### 완료한 항목도 다시 처리

완료한 항목은 기록으로 이동합니다. 다시 처리하려면 미완료 목록으로 복원하세요.

### 나중에 돌아오도록 알림

날짜와 시간을 정하고 시스템 알림을 허용하세요. 알림을 누르면 저장한 항목이 열립니다.

### Apple 기기 사이에서 이어서

같은 Apple 계정으로 로그인한 iPhone, iPad와 Mac 사이에서 iCloud로 동기화합니다. 네트워크와 iCloud 상태에 따라 지연될 수 있습니다.

현재 버전은 하루 저장 횟수에 제한이 없으며 별도의 Pro 업그레이드가 필요하지 않습니다. 지역별 제공 여부와 가격은 App Store에서 확인하세요.

iPhone, iPad, Mac용 CarryOver를 App Store에서 받으세요.
