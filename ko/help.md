# CarryOver 사용 방법

CarryOver는 링크, 텍스트, 관심 있는 순간을 지금 저장하고 나중에 알맞은 기기에서 검토하고 실행하도록 도와줍니다.

## 콘텐츠 저장

### 아무 앱이나 열기

Safari, 메모, 소셜 앱처럼 텍스트나 URL을 공유할 수 있는 앱에서 시작하세요.

### 공유 가능한 내용 선택

보관할 텍스트, 링크, 이미지 또는 게시물을 선택하세요. 공유할 수 있는 내용은 원본 앱에 따라 다릅니다.

### 공유 사용

지원하는 앱의 시스템 공유 메뉴에서 CarryOver를 선택하세요. iPhone과 iPad에 표시되지 않으면 더 보기를 확인하세요. Mac에서는 원본 앱, 콘텐츠 유형과 시스템 확장 설정에 따라 사용 가능 여부가 달라집니다.

### 확인하고 저장

공유 화면에서 내용을 확인하고 필요하면 제목을 수정하거나 알림을 설정하세요. 저장을 누르면 미완료 목록에 추가됩니다.

### 직접 기록 추가

CarryOver의 공유 추가 화면에서 아이디어를 기록하거나 내용을 붙여 넣은 뒤 미완료 목록에 저장하세요.

## 목록 관리

### 내용이나 출처 열기

항목을 선택해 보거나 편집하세요. 출처 URL이 있으면 출처 열기 동작으로 브라우저에서 열 수 있습니다.

### 처리 후 완료 표시

완료 버튼으로 처리한 항목을 기록으로 옮기세요. 완료한 항목만 기록으로 이동하며 미완료 항목은 만료되지 않습니다.

### 기록에서 복원

기록에서 항목 옆의 복원 버튼을 누르면 미완료 목록으로 돌아옵니다.

### 확인 후 삭제

iPhone과 iPad에서는 항목을 왼쪽으로 밀고 삭제를 선택하세요. Mac에서는 삭제 동작을 사용하세요. 확인한 뒤 삭제됩니다.

## 동기화와 문제 해결

### 같은 iCloud 계정 사용

같은 Apple ID로 로그인하고 iCloud를 사용할 수 있어야 합니다.

### 동기화 다시 시도

동기화 문제가 표시되면 상태 아이콘으로 다시 시도하세요.

### iCloud 저장 공간 확인

다른 기기에 바로 나타나지 않으면 iCloud 공간이나 백그라운드 업로드 상태를 확인하세요.

## 자주 묻는 질문

### CarryOver로 공유하려면 어떻게 하나요?

지원하는 앱의 시스템 공유 메뉴에서 CarryOver를 선택하세요. iPhone과 iPad에 표시되지 않으면 더 보기를 확인하세요. Mac에서는 원본 앱, 콘텐츠 유형과 시스템 확장 설정에 따라 사용 가능 여부가 달라집니다.

### 다른 기기에 바로 동기화되지 않아요.

네트워크, 저전력 모드, iCloud 저장 공간 부족으로 지연될 수 있습니다.

### CarryOver 계정이 필요한가요?

아니요. 가능한 경우 Apple의 iCloud 서비스로 동기화합니다.

### 미완료 항목은 며칠 뒤 사라지나요?

아니요. 미완료 항목은 계속 목록에 남습니다. 완료로 표시하면 기록으로 이동하고 삭제하면 제거됩니다.

### 저장한 내용을 검색할 수 있나요?

Mac 기본 창에서 제목, 본문과 출처 URL을 검색할 수 있습니다. 기록의 완료 항목도 포함합니다. iPhone과 iPad에는 현재 검색 기능이 없습니다.

### 나중에 처리하도록 실제 알림이 오나요?

네. 미래의 날짜와 시간을 설정하고 시스템 설정에서 CarryOver 알림을 허용하세요. 로컬 알림이 전달되지만 집중 모드나 알림 설정으로 소리가 나지 않을 수 있습니다. 알림을 누르면 해당 항목이 열립니다.

### 완료한 항목을 다시 처리할 수 있나요?

네. 기록에서 항목 옆의 복원 버튼을 누르면 미완료 목록으로 돌아옵니다.

### 무료 버전에는 무엇이 포함되나요?

무료 버전은 하루 최대 세 번 저장할 수 있습니다. Pro를 한 번 구매하면 일일 저장 제한이 해제됩니다. 지역별 가격은 App Store에서 확인하세요.

현재 기능을 사용하려면 App Store에서 받으세요. Mac 직접 다운로드 DMG는 아직 이번 버전으로 업데이트되지 않았습니다.
