다시 돌아오고 싶은 발견을 한곳에

iPhone이나 iPad에서 저장한 링크, 인용문, 이미지를 Mac에서 다시 열어 보세요. 제목이 생각나지 않아도 출처 도메인, 기억나는 구절, 당시 남긴 메모로 찾을 수 있습니다.

출퇴근길에 발견한 게시물

시스템 공유를 지원하는 소셜 앱에서 유용한 게시물을 저장하세요. Mac으로 돌아와 출처를 열고 자세히 확인할 수 있습니다.

다음 프로젝트를 위한 참고 자료

iPhone이나 iPad 공유 메뉴에서 링크, 인용문, 이미지를 저장하세요. ‘표본 수 확인하기’처럼 한 줄을 덧붙이면 Mac에서 열었을 때 왜 저장했는지 떠올릴 수 있습니다.

대화 뒤에 떠오른 아이디어

아이디어를 직접 메모하고 알림을 설정하세요. 시간이 날 때 이어서 처리하고, 끝나면 완료로 표시하세요.

빠르게 저장하고, 다음 행동으로 이어가세요

공유하거나 직접 기록

지원하는 앱의 시스템 공유 메뉴에서 텍스트, 링크 또는 이미지를 저장하세요. CarryOver에서 아이디어를 직접 기록할 수도 있습니다.

미완료 항목을 계속 보관

미완료 항목은 저장한 지 오래되어도 목록에 남습니다. 중요한 발견은 즐겨찾기하고, 실제로 처리한 뒤 완료로 표시하세요.

저장한 내용은 어디서나 검색

미처리 목록이나 기록에서 출처 도메인, 공유한 글의 일부, 개인 메모 또는 주제로 검색하세요.

완료한 항목도 다시 처리

완료한 항목은 기록으로 이동합니다. 다시 처리하려면 미완료 목록으로 복원하세요.

나중에 돌아오도록 알림

날짜와 시간을 정하고 시스템 알림을 허용하세요. 알림을 누르면 저장한 항목이 열립니다.

Apple 기기 사이에서 이어서

같은 Apple 계정으로 로그인한 iPhone, iPad와 Mac 사이에서 iCloud로 동기화합니다. 네트워크와 iCloud 상태에 따라 지연될 수 있습니다.

Markdown 내보내기

원래 자료는 그대로 두고 메모와 주제를 덧붙일 수 있습니다. 출처를 열어 내용을 확인하고 일이 끝나면 완료로 표시하세요. 글을 쓸 때는 항목 하나의 출처와 메모를 Markdown 파일로 내보낼 수 있습니다.

자주 묻는 질문

다른 앱에서 어떤 내용을 저장할 수 있나요?

출처 앱이 실제로 공유하는 텍스트, 링크 또는 이미지를 저장합니다. 소셜 게시물은 전체 내용 대신 링크로 공유될 수 있습니다. 원래 링크를 열려면 인터넷 연결이나 로그인이 필요할 수 있습니다.

먼저 저장하고 나중에 동기화할 수 있나요?

내용은 먼저 기기에 저장됩니다. 기기 간 동기화에는 동일한 Apple 계정, iCloud 활성화와 인터넷 연결이 필요합니다. 동기화 상태를 확인하고 필요하면 다시 시도하세요. 즉시 동기화가 보장되지는 않습니다.

제목을 잊은 자료는 어떻게 찾나요?

미처리 목록이나 기록에서 출처 도메인, 공유한 글의 일부, 개인 메모 또는 주제로 검색하세요. 검색 결과에서 출처를 열어 확인해도 자동으로 완료 처리되지 않습니다.

저장한 기사를 오프라인에서 읽을 수 있나요?

지원되는 공개 HTTPS 기사는 직접 텍스트 사본을 저장해 오프라인으로 읽을 수 있습니다. 기사 사본은 저장한 기기에만 남습니다. 항목 세부 정보 › 추가 작업 › 기사 사본 만들기
